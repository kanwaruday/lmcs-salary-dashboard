Academic Coordinator Guide

This guide explains how to read, interpret, and act on the Course Progress Dashboard — the central tool for verifying that all six LMS school teachers have correctly filled in their Course Mapping Google Sheets for Session 2026-27.

🎯

Purpose of This Dashboard

Who fills the data vs. who reads the dashboard

Teachers fill the Google Sheets — each sheet has one tab per class (M-I through Class 12) where teachers log every chapter's Term, Start Date, and CWA Date.

You read this dashboard — it automatically fetches those 6 sheets × 15 classes = 90 tabs of data and presents them in one place, so you can identify which teachers are behind, which courses have gaps, and exactly what action to take.

Are all 6 schools' course mappings complete?School cards — issue pills & donut ring
Which classes have unassigned chapters?Global stats bar → "Unassigned Chapters"
Which subjects haven't updated CWA dates?Drill → Action Plan → CWA Not Updated items
Is the T1/T2 chapter split within the target?Drill → Subject Detail → T1% / T2% columns

How the Dashboard Works

The dashboard reads live data directly from the six Course Mapping Google Sheets every time you open or refresh it. No manual export or data entry is needed.

1

Teacher fills the Google Sheet

Each teacher opens their school's Course Mapping Sheet, goes to their class tab (e.g., Class 5), and fills in the columns: Term (column F), Chapter Start Date (column H), and CWA Date (column K) for every chapter they teach.

2

Dashboard fetches data in real time

When you open this dashboard (or click Refresh), it pulls all 90 tabs across the 6 schools simultaneously. This takes about 5–15 seconds. Each school card shows a loading skeleton while data arrives.

3

Dashboard computes progress and flags issues

For every class and subject it counts chapters, checks which have Start Dates, which have CWA Dates, checks if the T1/T2 split meets the target, and generates specific action items. All of this matches the LMCS Course Progress Summary v4 standard.

4

You act on the flags

Open any school card → go to the Action Plan tab → read the specific issue and recommended action per class and subject → follow up with the relevant teacher.

⚡ Refresh after teacher updates

The dashboard shows data as of the last fetch. Once a teacher tells you they've updated the sheet, click the Refresh button (top right) to pull the latest data. The page does not auto-refresh.

Opening a School's Drill-Down Panel

Click anywhere on a school card (or the View Details → button) to open the slide-in panel for that school. The panel has three tabs: Class Overview, Subject Detail, and Action Plan.

Summary pills at the top of the panel

The coloured pills just inside the panel header show the school's T1 CWA %, T2 CWA %, Overall CWA %, Total chapters, and — if present — Unassigned count and Critical count. These give you a quick snapshot before diving into the tabs.

📋

One row per class (M-I through Class 12). All subjects for a class are combined into a single aggregate row here. Use this tab to quickly identify which classes are behind.

If a class row shows "Not available / skipped" it means the Google Sheet tab for that class either has no Term data entered yet (v4 auto-skip rule) or could not be fetched. Check the sheet directly and ensure the tab is named exactly as expected (e.g., Class 11, not Cl 11).

ℹ T1% measures distribution, not completion

A T1% of 62% means 62% of the subject's chapters have been assigned to Term 1 in the sheet — it does NOT mean 62% of chapters are finished. Completion is tracked separately via the CWA column.

Each action item shows:

●

Tags — Class · Subject · Severity

Coloured tags tell you exactly which class and subject the issue belongs to, so you know which teacher to contact.

●

Issue statement

A plain-English description of what the problem is — e.g., "T1: 5/12 Mathematics chapters have no CWA date ⚠ 2 past planned completion date".

●

▶ Recommended Action

A specific instruction you can read directly to the teacher or use as the basis for your follow-up message — including which column to update in the Google Sheet.

✓ No items = fully compliant

If the Action Plan tab shows a ✅ "No action items found" message for a school, all classes are fully mapped and CWA dates are up to date for that school. Well done to that school's teachers!

The 4 Status Values

Every subject-term combination is assigned exactly one of these four statuses, in the priority order shown below. The worst applicable status is always shown — so a subject showing "CWA Not Updated" has already passed the mapping check.

1 — ✗ Mapping Incomplete ✗ Mapping Incomplete

Trigger: One or more chapters for this subject have no Term assigned (Unassigned > 0).
Why it matters: Chapters without a Term are invisible to all other tracking. T1%, CWA%, and overdue counts are all wrong until this is fixed.
Fix: Teacher opens the Google Sheet → column F (Term) → fills in "Term 1" or "Term 2" for every blank row in this subject.
Priority: Highest — fix this first.

2 — ⚠ CWA Not Updated ⚠ CWA Not Updated

Trigger: All chapters are assigned to a Term, but one or more chapters are missing a CWA Date (column K).
Why it matters: The CWA (Course-Wise Assessment) date is the confirmation that a chapter has been taught and assessed. Without it, we cannot confirm progress.
Fix: Teacher opens the Google Sheet → column K (CWA Date) → fills in the date each chapter was completed. If marked ⚠ overdue, this is urgent.
Note: Not checked for Milestone classes (M-I, M-II, M-III) — shows "NA" instead.
Priority: Second — after mapping is complete.

3 — ↔ Distribution Issue ↔ Distribution Issue

Trigger: Mapping is complete and all CWA dates are filled, but the T1/T2 chapter split is outside the ±5% tolerance of the target.
Why it matters: An imbalanced split means either T1 is overloaded or T2 has too many chapters to cover in the available time.
Fix: Teacher reviews column F for this subject and reassigns chapters between T1 and T2 to meet the target split.
Priority: Third.

4 — ✓ Complete ✓ Complete

All checks passed: no unassigned chapters, all CWA dates filled, T1/T2 split within target (±5%). No action required for this subject.

Other status values you may see
  • Pending — T2 chapters not yet assigned (T2 chapter count = 0). Normal during T1 season; needs attention before T2 begins.
  • N/A — Shown for Milestone classes (M-I, M-II, M-III) where CWA is not applicable.
⚖️

Target T1/T2 Distribution

The dashboard checks that each subject's chapters are correctly split between Term 1 and Term 2. There are two targets depending on the class:

M-I, M-II, M-III, Class 1–9, Class 11
T1: 60%
T2: 40%
More chapters in T1 to account for the longer T1 season.
Acceptable range: T1 = 55%–65% (±5% tolerance)
Class 10 & Class 12
T1: 50%
T2: 50%
Equal split for board exam classes to ensure balanced revision time.
Acceptable range: T1 = 45%–55% (±5% tolerance)
⚠ ±5% tolerance is built in

A subject with T1 = 62% for a Class 7 subject is fine (within 55%–65%). A subject with T1 = 70% for Class 7 would flag as a ↔ Distribution Issue. The exact target percentages are also visible in the Action Plan remarks text for each flagged subject.

🌱

Milestone Classes (M-I, M-II, M-III)

CWA is not applicable for Milestone classes

Classes M-I (Montessori I), M-II, and M-III follow a different assessment model — there is no CWA date requirement.

On the dashboard:

  • The T1 CWA and T2 CWA columns in Subject Detail show NA
  • The status check skips the "CWA Not Updated" condition — a Milestone class can only flag as "Mapping Incomplete" (unassigned chapters), "Distribution Issue", or "Complete"
  • The class header in Subject Detail shows Milestone class — CWA not applicable
You still need to ensure that all Milestone chapters are assigned to a Term and that the T1/T2 split meets the 60/40 target.

Weekly Compliance Routine

Follow this routine every week to ensure all 6 schools are on track:

1

Open the dashboard and refresh

Visit course-progress.html (linked from the Tools Hub). Click Refresh to pull the latest data from all 6 sheets.

2

Check the global stats bar first

Look at Unassigned Chapters and Critical Issues. If either is non-zero, these need to be resolved before anything else. Note which schools have a red card border.

3

Open each school with issues

Click on schools that show red issue pills. Go directly to the Action Plan tab. Start from the 🔴 Critical section at the top.

4

Follow up with teachers

For each action item: note the Class, Subject, and Recommended Action. Contact the relevant teacher with specific instructions (the action text in the panel tells you exactly which column to update). Give a deadline — same day for Critical, 3–5 days for Attention.

5

Re-check after teacher updates

Once the teacher says they've updated the sheet, refresh the dashboard and verify the issue has cleared. A subject should move from ✗ Mapping Incomplete to ⚠ CWA Not Updated to ✓ Complete over time.

6

Before T2 begins (October 2026)

Review all Plan Ahead items in every school. All subjects must have T2 chapters assigned (column F = "Term 2") before T2 teaching starts in November.

What Teachers Must Fill — Column by Column

Share this with teachers when following up. All required columns are in the Google Sheet under their class tab.

ColumnField NameWhat to enterDashboard uses it forPriority
F Term Type exactly Term 1 or Term 2 for every chapter row T1/T2 distribution %; Unassigned count; all status checks 🔴 Mandatory — fill before anything else
H Chapter Start Date Enter the date teaching of that chapter begins (DD-Mon-YYYY format recommended) Scheduled count; overdue detection 🟡 Fill when chapter is planned
I No. of Days Planned Enter the number of teaching days planned for that chapter Overdue detection (Start Date + Days < today without CWA = overdue) 🟡 Fill when chapter is planned
K CWA Date Enter the date the chapter's CWA (Course-Wise Assessment) was conducted — once the chapter is fully taught and assessed CWA completion %; overdue flag cleared; status = Complete 🔴 Mandatory — fill once chapter is done
⚠ Common teacher mistakes that cause red flags
  • Leaving the Term column (F) blank — causes "Mapping Incomplete" for the subject
  • Typing "T1", "Term1", or "1" instead of "Term 1" — the dashboard won't recognise it and marks the row as unassigned
  • Forgetting to update column K (CWA Date) after completing a chapter — the chapter stays flagged as "not updated" and may become overdue
  • Using "Term 2/1" for shared chapters — this is ambiguous and can cause double-counting; assign to one term only

Troubleshooting

Problem you seeLikely causeFix
Yellow notice bar: "Some sheets couldn't be loaded" One or more sheets are not set to "Anyone with the link → Viewer" Open the affected Google Sheet → Share → General Access → change to "Anyone with the link" → Viewer → Done. Then Refresh the dashboard.
A school card stays on "Fetching data…" for > 30 seconds Network issue or all tabs of that school failed to load Check your internet connection. Try clicking Refresh. If it persists, open the Google Sheet directly to verify it's accessible.
A class shows "Not available / skipped" Tab name doesn't match exactly, or the tab has no Term data at all Open the Google Sheet and verify the tab is named exactly: M-I, M-II, M-III, Class 1 through Class 12. Capitalization and spaces matter.
All subjects in a class show 0 unassigned but status is still "Mapping Incomplete" Data may not have refreshed yet after teacher edit Click the Refresh button. Allow 10–15 seconds for all tabs to reload.
T1 CWA shows 0% for a class even though teacher says chapters are done Teacher has not filled column K (CWA Date) Ask teacher to open the sheet, go to the class tab, find all completed chapter rows, and enter the CWA date in column K. Then Refresh.
Overdue count (⚠) appears but teacher says the chapter was covered CWA Date (column K) was not filled even though chapter is complete Teacher must enter the actual CWA date in column K. The overdue flag disappears once K is filled.
Distribution Issue for a subject even though T1/T2 seems balanced Some chapters still have blank Term (unassigned), reducing the denominator Fix unassigned chapters first (column F). The distribution % recalculates automatically once all rows have a term.
Class 9 shows wrong column data (subjects look garbled) Class 9 has an extra "Unit No." column that shifts standard columns The dashboard handles this automatically via column header detection. If you see garbled data, the sheet headers in Class 9 may have been altered — check that row 2 headers match the standard template.
ℹ Need further help?

If the dashboard shows unexpected data after verifying all the above, contact the LMCS admin team. Include a screenshot of the issue and the name of the school and class where the problem appears.
