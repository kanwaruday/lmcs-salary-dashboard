Payroll Sheet — Apps Script Web App URL
Paste the URL of your deployed Google Apps Script Web App below. The hiring dashboard will POST every "Submit to Accounts" entry to this URL, which writes one row into your Employee_Master sheet.
How to get this URL
1Open script.google.com → open or create the project from apps-script/Code.gs
2Replace YOUR_PAYROLL_GOOGLE_SHEET_ID_HERE in Code.gs with your Payroll Sheet ID
3Click Deploy → New Deployment → Web App — set Execute as: Me, Access: Anyone
4Copy the Web App URL and paste it above
