Schools & Data Sources

Set the display name and Google Sheet for each school. The Sheet ID is the long alphanumeric string from the Google Sheets URL: docs.google.com/spreadsheets/d/SHEET_ID/edit

Before changing a Sheet ID Ensure the new sheet is shared as "Anyone with the link → Viewer" and follows the same column layout (Subject in col B, Term in col F, Start Date in col H, CWA Date in col K). The dashboard auto-detects column positions from headers.

Class Configuration

Configure the expected T1/T2 chapter distribution target and whether CWA tracking applies for each class. The Sheet Tab Name must exactly match the tab name in the Google Sheet (case-sensitive, spaces matter). T2 target is automatically set to 100 − T1.

Distribution targets explained A T1 target of 60% means 60% of chapters should be assigned to Term 1 in the course mapping sheet (column F). The dashboard flags any subject where the actual split falls outside ±Tolerance of this target.

CWA-Exempt Subjects

Subjects listed here are never counted for CWA tracking, regardless of which class or school they appear in. Use this for subjects like General Knowledge and Computer that do not have formal CWA assessments. Matching is case-insensitive.

Where this applies The Daily Progress tracker will not count CWA tags for these subjects. The Course Mapping dashboard will skip CWA completion calculations for them too.
